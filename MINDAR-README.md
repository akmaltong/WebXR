# 🍔 BurgerAR Menu - MindAR Edition

## 📋 Описание

Это **альтернативная версия** AR-меню на базе **MindAR** - библиотеки для трекинга изображений (marker-based AR).

В отличие от WebXR версии (markerless AR), эта версия использует **карточки-маркеры** для отображения 3D моделей блюд.

---

## 🎯 Как это работает

1. **Печатаете карточки меню** с уникальными изображениями-маркерами
2. **Клиент наводит камеру** на карточку через телефон
3. **3D модель бургера появляется** прямо на карточке
4. **Клиент может заказать** нажав кнопку "Заказать"

---

## 🚀 Запуск

### Локально (для разработки):

```bash
npm run start
# или
npm run serve
```

Откройте: `http://localhost:8000/mindar-menu.html`

⚠️ **Важно:** Для работы камеры нужен **HTTPS** или `localhost`

## 🎨 Преимущества MindAR версии

### ✅ Что лучше чем WebXR:

1. **Множественные блюда** - каждая карточка = своя модель
2. **Стабильный трекинг** - модель "прилипает" к карточке
3. **iOS поддержка** - работает в Safari
4. **Полный контроль** - A-Frame дает больше возможностей
5. **Нет проблем с размещением** - не нужно сканировать поверхность

### ❌ Что хуже:

1. **Нужны маркеры** - требуется печать карточек
2. **Не работает без маркера** - нельзя просто поставить на стол
3. **Зависимость от освещения** - маркер должен быть хорошо виден

## 🔧 Настройка для нескольких блюд

### 1. Создайте свои маркеры

Используйте **MindAR Image Compiler**:
https://hiukim.github.io/mind-ar-js-doc/tools/compile

1. Загрузите изображения ваших карточек (до 10 штук)
2. Скачайте `.mind` файл
3. Замените в коде:

```html
<a-scene
    mindar-image="imageTargetSrc: ./your-markers.mind;">
```

### 2. Добавьте маркеры в HTML

```html
<!-- Маркер #0 - Классический бургер -->
<a-entity mindar-image-target="targetIndex: 0">
    <a-gltf-model src="./burger1.glb" scale="3 3 3"></a-gltf-model>
</a-entity>

<!-- Маркер #1 - Чизбургер -->
<a-entity mindar-image-target="targetIndex: 1">
    <a-gltf-model src="./burger2.glb" scale="3 3 3"></a-gltf-model>
</a-entity>

<!-- Маркер #2 - Веган бургер -->
<a-entity mindar-image-target="targetIndex: 2">
    <a-gltf-model src="./burger3.glb" scale="3 3 3"></a-gltf-model>
</a-entity>
```

### 3. Обновите данные блюд в JavaScript

```javascript
const dishes = {
    0: {
        name: '🍔 Классический бургер',
        description: 'Сочная говяжья котлета',
        price: '450 ₽',
        model: './burger1.glb'
    },
    1: {
        name: '🧀 Чизбургер',
        description: 'С двойным сыром чеддер',
        price: '520 ₽',
        model: './burger2.glb'
    },
    2: {
        name: '🌱 Веган бургер',
        description: 'Растительная котлета Beyond Meat',
        price: '580 ₽',
        model: './burger3.glb'
    }
};
```

## 🎨 Дизайн карточек меню

### Рекомендации для маркеров:

1. **Высокий контраст** - четкие детали
2. **Уникальные паттерны** - не должны быть похожи
3. **Размер:** минимум 10x10 см для печати
4. **Формат:** PNG/JPG, разрешение 1024x1024px или выше
5. **Избегайте:**
   - Однотонных изображений
   - Размытых фото
   - Симметричных паттернов

### Пример дизайна карточки:

```
┌─────────────────────────┐
│  [Уникальное изображение]│
│     (маркер для AR)      │
│                          │
│  🍔 Классический бургер  │
│  Сочная котлета, овощи   │
│         450 ₽            │
│                          │
│  📱 Наведите камеру      │
│     для AR просмотра     │
└─────────────────────────┘
```

## 🐛 Решение проблем

### Камера не запускается
- Проверьте HTTPS или используйте localhost
- Разрешите доступ к камере в настройках браузера

### Маркер не распознается
- Улучшите освещение
- Держите камеру ближе/дальше
- Убедитесь что маркер не размыт

### Модель не загружается
- Проверьте путь к .glb файлу
- Откройте консоль браузера (F12) для ошибок

### Низкая производительность
- Уменьшите полигоны 3D модели
- Используйте Draco compression для glTF
- Отключите сложные эффекты
