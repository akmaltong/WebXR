## ✅ Что уже проделано

- [x] **3D модель бургера** - загружается и отображается (Hamburger2.glb)

- [x] **Размещение на полу** - ar-placement="floor" активен

- [x] **Инструкция перед AR** - модальное окно с 4 шагами
- [x] **Зеленый сканер поверхности** - визуальный индикатор сканирования

- [x] **Подсказки на экране** - "Сканирование..." и "Готово!"

### 4. Техническая база

## 📝 Примечания разработчика

### Полезные ссылки:
- [Model Viewer Docs](https://modelviewer.dev/docs/)
- [WebXR Device API](https://immersiveweb.dev/)
- [ARCore Supported Devices](https://developers.google.com/ar/devices)

### Технические ограничения Model Viewer:
- Автоматическое размещение при обнаружении поверхности
- Ограниченный контроль над рендерингом AR
- Нет возможности получить hit-test данные напрямую

### Альтернативы (если Model Viewer не подойдет):
- Three.js + WebXR (полный контроль)
- 8th Wall (коммерческое решение)
- Unity WebGL + WebXR (сложнее, но мощнее)
