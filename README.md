# 🍔 BurgerAR - Меню будущего

Прогрессивное AR-меню без маркеров. Гости видят еду прямо на своем столе через браузер.

🔗 **[Попробовать Демо Версию](https://akmaltong.github.io/WebXR/mindar-menu.html)**

---

## 🚀 Как это работает

1.  Гость **сканирует QR-код** блюда.
2.  Открывается страница с красивой 3D моделью.
3.  Нажимает кнопку **"Поставить на стол"**.
4.  Камера включается, и сочный бургер стоит на реальном столе!

⭐ **Преимущества:**
*   ❌ **БЕЗ приложения** (работает прямо в браузере)
*   ❌ **БЕЗ маркеров** (не нужно печатать странные черно-белые картинки)
*   ✅ **Нативный AR** (использует встроенные AR-движки iOS и Android)
*   ✅ **Одна страница** для всех блюд

## 🛠 Как добавить новый бургер

### 1. Подготовьте модель
Вам нужен файл формата `.glb` (максимально легкий, до 10-15 МБ).
Назовите его понятно, например: `burger_cheese.glb`.

### 2. Загрузите в проект
Положите файл `.glb` в папку с проектом и отправьте на GitHub.

### 3. Добавьте в базу данных
Откройте файл `mindar-menu.html`, найдите `menuDatabase` и добавьте новую строчку:

```javascript
'new_burger': {
    name: 'Супер Бургер',
    price: '600 ₽',
    desc: 'Описание вашего бургера',
    model: './new_burger.glb' // Имя вашего файла
},
```

### 4. Создайте QR-код
Ссылка для QR-кода будет такой:
`https://akmaltong.github.io/WebXR/mindar-menu.html?id=new_burger`

Где `new_burger` — это ключ, который вы придумали в шаге 3.

## 📱 Совместимость

*   **iPhone (iOS 12+)**: Работает отлично через ARKit (Quick Look).
*   **Android (8.0+)**: Работает отлично через ARCore (WebXR).
*   **Старые телефоны**: Просто показывают 3D модель (можно крутить пальцем), но без камеры.
