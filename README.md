# 🍔 BurgerAR

Веб-приложение для просмотра бургера в 3D и дополненной реальности (AR) через QR-коды.

## 🎯 Две версии проекта

### 1️⃣ **WebXR версия** (`index.html`) - Markerless AR
- ✅ Размещение на **любой поверхности** (стол, пол)
- ✅ Не требует маркеров/карточек
- ❌ Только Android Chrome (WebXR)
- ❌ Проблемы с контролем размещения

### 2️⃣ **MindAR версия** (`mindar-menu.html`) - Marker-based AR ⭐ **НОВОЕ**
- ✅ Стабильный трекинг на **карточках меню**
- ✅ Работает на **iOS Safari** и Android
- ✅ Множественные блюда (каждая карточка = своя модель)
- ✅ Полный контроль через A-Frame
- ❌ Требует печать карточек-маркеров

📚 **Подробнее о MindAR версии:** [MINDAR-README.md](./MINDAR-README.md)

---

## 📱 Как это работает

### WebXR версия (index.html):
1. Гость сканирует QR-код на столе камерой телефона
2. Открывается страница с 3D моделью бургера
3. Можно вращать и приближать бургер пальцем
4. Кнопка "Посмотреть в AR" запускает AR режим
5. AR находит поверхность стола и размещает бургер
6. Гость двигает телефоном чтобы осмотреть бургер со всех сторон

### MindAR версия (mindar-menu.html):
1. Гость сканирует QR-код или открывает ссылку
2. Наводит камеру на **карточку меню** с маркером
3. 3D модель бургера появляется **прямо на карточке**
4. Можно нажать "Заказать" для оформления заказа

## 🚀 Запуск

### Локально для теста:

```bash
# Python
python -m http.server 8000

# Node.js
npx http-server -p 8000
```

Откройте: http://localhost:8000

### Для QR-кодов (обязательно HTTPS):

Загрузите на GitHub Pages, Netlify или любой хостинг с SSL.

## ✅ Поддерживаемые устройства

### WebXR версия (index.html):
**Android:** Chrome 83+, Samsung Internet 12+  
**iOS:** Safari 13+ (через Quick Look, ограниченно)

### MindAR версия (mindar-menu.html):
**Android:** Chrome 83+, Firefox 68+, Samsung Internet 12+  
**iOS:** Safari 13+ (полная поддержка AR) ✅  
**Desktop:** Работает для разработки (без камеры)

## 🔧 Технические детали

- **WebXR** - нативный AR в Chrome Android
- **Quick Look** - AR на iOS через USDZ
- **Model Viewer** - библиотека Google для 3D/AR
- **Требования:** HTTPS для AR, доступ к камере

## 📋 QR-коды

После размещения на GitHub Pages:
1. URL будет: `https://ваш-username.github.io/WebXR/`
2. Сгенерируйте QR-код на этот URL
3. Разместите QR-код на столах

## ⚠️ Важно

- HTTPS обязателен для WebXR AR
- На iOS AR работает через Quick Look (открывается отдельно)
- Размер QR-кода минимум 10x10 см для сканирования
